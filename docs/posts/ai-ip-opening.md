# 开篇：一个运维工程师的 AI 笔记

> 2026-10-10 · 阅读约 3 分钟

我是孙佳丽，一个做了多年运维的工程师。K8s、Prometheus 是我的老本行，半夜被报警短信叫醒的日子没少过。

但这两年，我把越来越多的时间花在了 AI 上。

## 为什么转向 AI

不是跟风，是有几个很具体的触动。

第一个触动是效率。以前写一个运维脚本，从查文档到调试，半天没了。现在我把需求描述清楚，AI 帮我搭出初版，我只负责 review 和改关键逻辑。**同样的时间，我能做三倍的事。** 这种体感一旦有过，就回不去了。

第二个触动是 Karpathy 说的那句话："The hottest new programming language is English." 干了这么多年技术，我第一次觉得，表达能力正在变成和写代码同等重要的生产力。

第三个触动是 Agent。2026 年，Agent 从"玩具"变成了"生产力"——能自己规划、自己执行、自己修正，还能自我改进（比如 Dream-RSI 那套递归自我改进的思路）。运维人最懂"自动化"的价值，而 Agent 是自动化的下一站。

## 这个博客写什么

想清楚了，就写三件事，都是我自己真实在折腾的：

1. **AI 提效实战**：我真实在用的工具、方法和踩过的坑，不写没用过的东西
2. **Agent 前沿追踪**：从 Dream-RSI 到 Karpathy 的 RSI，把最前沿的进展翻译成工程师能用的东西
3. **内容创作**：用 AI 做小红书、写东西，验证"一个人就是一支队伍"
